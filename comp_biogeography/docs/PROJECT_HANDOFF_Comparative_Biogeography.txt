## PROJECT OVERVIEW

Use the hex grid framework to compare geographic distributions of lichen
taxa across CONUS48, testing whether **absence-weighted vectors** provide
stronger biogeographic signal than traditional **presence-only vectors**.

This is the controlled experiment to validate the core aposologic hypothesis:
that informed absences contain biogeographic information that improves
species distribution comparisons beyond what presence data alone provides.

**Central Question**: Does adding weighted absence information to species
distribution vectors improve the detection of biogeographic patterns
compared to presence-only methods?


## THE FUNDAMENTAL TEST

### Method A (Traditional): Presence-Only Vectors
Each taxon represented as binary vector across hex cells:
- 1 = species present in cell
- 0 = ignored (treated as missing data)
- Distance measures: Jaccard, Sørensen on presence data only
- Standard approach in biogeography and community ecology

### Method B (Aposologic): Presence + Weighted Absence Vectors  
Each taxon represented as weighted vector across hex cells:
- 1 = species present in cell
- 0.8 = high-confidence absence (well-collected cell, species not found)
- 0.3 = medium-confidence absence (moderately collected)
- 0 = uninformed absence (empty or nearly empty cell)
- Distance measures: modified Bray-Curtis or custom metric handling weights

### Validation Framework
Compare Method A vs Method B on their ability to:
1. **Cluster related species** - do congeners group together?
2. **Separate ecological guilds** - do substrate specialists cluster?
3. **Recover known biogeographic patterns** - elevation zones, regional floras
4. **Predict range boundaries** - where species actually stop vs data gaps

If Method B consistently outperforms Method A, the aposologic framework
is validated. If not, absence weighting adds noise rather than signal.


## WHY THIS APPROACH IS NOVEL

### What's Been Done Before

**Species co-occurrence analysis**:
- Focuses on which species are found together at sites
- Uses presence data only, ignores absences
- Questions: community assembly, niche overlap, competition

**Range overlap studies**:
- Computes Jaccard/Sørensen indices between species ranges
- Binary presence/absence maps, no weighting of absence quality
- Questions: conservation priorities, climate change vulnerability

**Ecological niche modeling (MaxEnt, etc.)**:
- Tries to predict suitable habitat from presence + environmental data
- Treats absences as uninformative (presence-only modeling)
- Questions: habitat suitability, invasion risk, climate impacts

**Phylogeography**:
- Compares distributions of related species for evolutionary inference
- Range overlap metrics, molecular + distribution data
- Questions: speciation patterns, dispersal history, refugia

### What's Missing: Aposologic Information

None of these approaches use **informed absence** as a positive signal.
They either:
- Ignore absences entirely (presence-only)
- Treat all absences as equal (binary presence/absence)
- Try to model around absences (niche modeling with pseudo-absences)

**The novel contribution**: Use the **spatial structure of absences**
as information about species relationships. A species absent from
well-collected cells where a related species is present tells you
something about their ecological differences or geographic limits.


## ANALYTICAL FRAMEWORK

### Step 1: Build Species Vectors

For each taxon in CLH with >50 records and >10 occupied hex cells:

**Extract records**:
```sql
SELECT scientificNameRegularized as taxon, hex_id
FROM specimens_with_hex  -- join of CLH records with hex assignments
WHERE scientificNameRegularized LIKE '% %'  -- species level only
  AND scientificNameRegularized NOT LIKE '% sp.'
GROUP BY scientificNameRegularized
HAVING COUNT(*) >= 50  -- minimum records threshold
;
```

**Create presence vector** (Method A):
For each taxon, binary vector across hex cells:
```r
presence_vectors <- species_by_hex_matrix > 0  # TRUE/FALSE
```

**Create weighted vector** (Method B):
For each taxon, weighted vector considering absence confidence:
```r
# For each hex cell, compute absence confidence based on:
# - Total specimens in cell
# - Number of collectors in cell  
# - Genus breadth in cell (proxy for sampling completeness)
# - Substrate breadth (corticolous vs. saxicolous vs. terricolous)

cell_confidence <- function(hex_data) {
  base_conf <- min(1.0, n_specimens / 100)  # specimen density
  collector_conf <- min(1.0, n_collectors / 5)  # collector diversity
  genus_conf <- min(1.0, n_genera / 20)  # taxonomic breadth
  return(mean(c(base_conf, collector_conf, genus_conf)))
}

# Apply to create weighted absence vectors
weighted_vectors[taxon, hex] <- ifelse(
  present = 1,
  absent = cell_confidence[hex],  # weighted absence
  no_data = 0  # uninformed absence
)
```

### Step 2: Distance Matrices

**Method A distances**: Standard binary measures
```r
library(vegan)
dist_presence <- vegdist(presence_vectors, method = "jaccard", binary = TRUE)
```

**Method B distances**: Handle weighted absences
```r
# Custom distance function that uses absence weights
weighted_jaccard <- function(x, y) {
  intersection <- sum(pmin(x, y))  # minimum of presence/absence weights
  union <- sum(pmax(x, y))  # maximum of presence/absence weights
  return(1 - intersection/union)  # Jaccard-style with weights
}

dist_weighted <- apply_pairwise(weighted_vectors, weighted_jaccard)
```

### Step 3: Validation Tests

**Test 1: Taxonomic Signal**
- Cluster species using Method A vs Method B
- Count how often congeners (same genus) cluster together
- Expected: related species should group more consistently with Method B
- Metric: cophenetic correlation, silhouette scores within genera

**Test 2: Ecological Signal** 
- Group species by known ecological preferences:
  - Substrate: corticolous vs saxicolous vs terricolous
  - Elevation: alpine vs montane vs lowland specialists
  - Region: eastern vs western North American distributions
- Test which method separates ecological groups more clearly
- Metric: ANOSIM R-statistic, PERMANOVA on groupings

**Test 3: Biogeographic Signal**
- Project species ordinations (PCA/NMDS) from Method A vs Method B
- Compare with known biogeographic patterns:
  - Continental divide (east-west split)
  - Elevation gradients (alpine vs lowland floras)
  - Regional endemism (Pacific Northwest, Sonoran Desert, etc.)
- Expected: Method B should show sharper biogeographic structure
- Metric: stress values, correlation with environmental gradients

**Test 4: Range Boundary Detection**
- For species with well-known range limits, compare predicted vs. actual boundaries
- Method A: boundary = edge of presence records
- Method B: boundary = transition from presence to high-confidence absence
- Expected: Method B boundaries closer to published range maps
- Metric: distance between predicted and literature-based range edges

### Step 4: Comparative Analysis

**Statistical comparison**:
```r
# Compare clustering quality
mantel_test(dist_presence, known_taxonomy_matrix)
mantel_test(dist_weighted, known_taxonomy_matrix)

# Compare ordination stress
nmds_presence <- metaMDS(dist_presence)
nmds_weighted <- metaMDS(dist_weighted)
```

**Effect size calculation**:
- How much does Method B improve signal detection?
- Which types of species benefit most from absence weighting?
- Are there cases where Method A outperforms Method B?


## EXPECTED OUTCOMES

### If Aposologic Method Succeeds:

1. **Stronger taxonomic signal**: Congeners cluster together more consistently
   with Method B than Method A. Higher cophenetic correlation with taxonomy.

2. **Clearer ecological separation**: Substrate specialists, elevation zones,
   and regional floras separate more distinctly in Method B ordinations.

3. **Sharper biogeographic patterns**: Continental divide, elevation gradients,
   and regional boundaries emerge more clearly with weighted absences.

4. **Better range boundary prediction**: Method B boundaries closer to
   published range limits than Method A boundaries.

5. **Consistent improvement**: Method B outperforms Method A across multiple
   validation tests and taxonomic groups.

### If Traditional Method Wins:

1. **Absence = noise**: Weighted absences obscure rather than clarify patterns.
   Method A consistently outperforms Method B.

2. **Collector bias overwhelming**: Absence patterns track collecting effort
   rather than biogeography, adding confounding signal.

3. **Scale mismatch**: Hex grid resolution inappropriate for species-level
   distributions. Presence-only more robust to scale effects.

### Mixed Results (Most Likely):

4. **Context-dependent value**: Method B helps for some taxonomic groups
   (widespread genera) but not others (rare endemics).

5. **Signal vs. noise trade-off**: Method B improves signal for well-collected
   regions but adds noise in poorly-collected areas.

6. **Methodological refinement needed**: Basic concept valid but weighting
   scheme, distance measures, or confidence metrics need adjustment.

## POTENTIAL COMPLICATIONS

### Data Issues
- **Taxonomic uncertainty**: synonymy, misidentifications
- **Spatial error**: coordinate precision, georeferencing problems
- **Temporal bias**: collecting effort changes over time
- **Institutional bias**: some herbaria focus on specific regions/groups

### Methodological Challenges
- **Distance measure selection**: what works best for weighted absences?
- **Confidence weighting**: how to calibrate absence confidence scores?
- **Scale effects**: optimal hex grid resolution for species comparisons?
- **Rare species**: do methods work for species with few records?

### Validation Difficulties
- **Literature bias**: published range maps may be presence-only themselves
- **Circular reasoning**: using lichen literature to validate lichen analysis
- **Environmental confounding**: biogeographic patterns reflect climate, not just collecting

### Computational Constraints
- **Matrix size**: ~1000 species × ~2000 hex cells = 2M cell matrix
- **Distance calculations**: pairwise comparisons scale as N²
- **Memory requirements**: multiple large matrices in memory
